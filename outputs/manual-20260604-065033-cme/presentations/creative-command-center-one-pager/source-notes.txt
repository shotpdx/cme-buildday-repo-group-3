Current solution summary:
The repository implements a CME Build Day Creative Command Center solution for buy-side campaign workflows. It includes a React + FastAPI Databricks App, Databricks Asset Bundle configuration, Lakeflow pipeline resources, gold-layer buyside tables, CSV fallback data, governed creative generation flows, policy and synthetic evaluation surfaces, activation lineage, and Genie/Ask AI decision support. The app can read Databricks SQL pipeline tables or fall back to local CSV extracts.

- Creative workflows support brief/audience selection, governed asset retrieval, image/video generation options, transformations, brand guideline context, variant approval, synthetic evaluation, policy checks, activation exports, and lineage.
- Databricks platform components include Databricks Apps, Lakeflow pipelines, Unity Catalog, Delta tables, Vector Search, Model Serving / Foundation Model endpoints, Genie, and Lakebase-style state persistence.
